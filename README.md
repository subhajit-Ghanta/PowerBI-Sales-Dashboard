# 📊 Mobile Sales Analysis Dashboard — Power BI

## 📌 Project Overview

This project is an interactive **Mobile Sales Analysis Dashboard** developed using **Microsoft Power BI**. The dashboard provides a comprehensive view of mobile phone sales performance, quantities sold, transactions, customer ratings, payment methods, brands, cities, mobile models, and time-based sales trends.

The goal of this project is to transform raw mobile sales data into meaningful business insights through an interactive and visually appealing dashboard.

---

## 🎯 Project Objectives

The main objectives of this dashboard are to:

* Analyze overall mobile sales performance.
* Track total sales and total quantity sold.
* Monitor transaction volume.
* Identify sales trends across different months and days.
* Compare sales performance across mobile models.
* Analyze sales by brand and city.
* Understand customer rating distribution.
* Analyze customer payment preferences.
* Provide interactive filtering using monthly slicers.
* Present key business KPIs in an easy-to-understand format.
